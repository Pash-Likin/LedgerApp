# 轻记账 (LedgerApp)

一款运行在安卓手机上的轻量级个人记账 App（基于 **Expo SDK 58 + React Native + TypeScript + 安卓原生 Kotlin 模块**），所有数据保存在设备本地，支持日常支出/收入记录、自定义收支分类、月度收支统计图表、按月导出 **CSV / PDF 账单**、**安卓通知栏/无障碍实时自动记账**以及**手机桌面小组件**。

## 核心功能

- **快速记账（明细页 & 中央 `+` 记一笔）**
  - 支持 **支出 / 收入** 切换，内置防浮点误差的 `+ / -` 计算器键盘。
  - 支持快捷日期（今天 / 昨天 / 前天）与完整中文日历选择器、文字备注及分类图标网格。
  - 按日期分组展示每日明细与日收支小计，支持按收支类型过滤与关键词搜索，点击任意账单可编辑或删除。
- **安卓实时自动记账（通知监听 + 无障碍 + 通知栏确认）**
  - 原生监听微信、支付宝、美团、美团外卖、云闪付、京东、拼多多、抖音的支付/收款/退款通知，也可在支付成功页面通过无障碍服务兜底识别。
  - 识别到有效金额与商户后，自动推荐分类并**弹出一条可交互通知**：可直接点「记为「推荐分类」」一键入账，或点「选分类」进入 App 确认弹窗修改金额/类型，或点「忽略」。
- **手机桌面小组件（4×2 月度概览）**
  - 在安卓手机桌面展示本月支出、收入、结余及最近一笔账单，点击右上角「+ 记一笔」秒开记账弹窗。
  - 支持在 App 内的「自动记账与桌面小组件」中心一键请求添加至桌面，或通过桌面手势添加。
- **收支统计（统计页）**
  - 按月切换查看支出或收入构成：环形占比图（点击高亮分类）、每日柱状趋势图（日均、单日最高与单日明细提示）、分类排行进度条及展开明细。
- **月度账单导出（导出页）**
  - **CSV 账单（`.csv`）**：带 UTF-8 BOM 头，直接在 Excel / WPS 中打开无中文乱码，包含全部交易明细与月度汇总。
  - **PDF 月度报告（`.pdf`）**：A4 排版报告，包含总支出/总收入/月度结余/记录笔数卡片、分类占比条与完整时间序明细表。
  - 安卓端生成后自动调用系统分享面板，支持**历月账单快速导出**。
- **自定义分类与数据管理（分类页）**
  - 内置 10 个常用支出分类和 6 个常用收入分类，支持自由新增、编辑名称/图标/颜色或删除分类（删除时历史记录自动迁移至保底分类，不会丢失账目）。

## 如何在安卓手机上打包安装（EAS Build）

> **提示**：由于「通知监听服务」「无障碍服务」和「桌面小组件」包含安卓原生 Kotlin 代码（位于 `modules/auto-ledger`），**必须打包独立 APK 安装包才能体验完整功能**（通用的 Expo Go 不包含自定义原生模块）。

在 `d:\Code\Gemini\LedgerApp` 目录打开 PowerShell 运行（因本地未安装 Git，需设置 `EAS_NO_VCS=1`）：

```powershell
cd d:\Code\Gemini\LedgerApp
$env:EAS_NO_VCS="1"
npx eas-cli login
npx eas-cli build -p android --profile preview
```

编译完成后，用安卓手机扫描二维码或点击构建链接下载安装 `.apk` 即可。

### 手机端首次启用自动记账与桌面小组件
1. 打开 **轻记账**，点击首页右上角铃铛图标（或进入「分类 → 自动记账与桌面小组件」）。
2. 依次开启：
   - **弹出确认通知权限**（Android 13+ 必开，否则无法弹出确认通知）
   - **通知栏使用权**（授权给“轻记账通知自动记账”）
   - **无障碍服务**（可选兜底，开启“轻记账无障碍自动记账”）
3. 点击页面内的 **「模拟美团外卖 ¥36.50」** 即可立刻看到通知栏弹窗确认效果。
4. 点击 **「一键添加到手机桌面」** 将「轻记账 · 月度概览」小组件放到桌面（部分国产桌面如拦截弹窗，可在桌面长按空白处 → 小组件/插件中手动添加）。

## 浏览器预览与测试

```bash
cd d:\Code\Gemini\LedgerApp
npm run web         # 在电脑浏览器中预览界面（无原生监听/桌面组件）
npm run typecheck   # 运行 TypeScript 全量类型检查
npm test            # 运行金额、日期、统计、导出与支付文本识别单元测试
```
